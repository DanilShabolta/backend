# Информационный портал для образования

## Содержание

Данные лабораторные работы будут содержать backend - часть приложения, которая будет взаимодействовать с базой данных и предоставлять данные. В качестве backend - части будет использоваться Node.js с Express.js.

## Технологический стек

### backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT для аутентификации

## структура проекта

```
src/
controller/ # контроллеры
model/ # модели для бд
router/ # маршрутизаторы
services/ # бизнес логика
utils/ # вспомогательные функции
middlewares/ # middleware
app.js # основной файл приложения
```

## Установка и запуск

### Требования для запуска

- Node.js (16+)
- MongoDB (5+)
- yarn

### Установка зависимостей

```bash
yarn install
```

### Запуск в режиме разработки

```bash
yarn dev
```

### Сборка для прода

```bash
yarn build
```
